# 💼 Financial Data Analytics Solution  

### 🎓 Final Year Project — Business Intelligence & Data Engineering  

This project presents the **design and implementation of a complete Business Intelligence system** for analyzing financial transactions, detecting anomalies, and supporting decision-making in the banking sector.  

---

## 🧩 Project Overview  

The goal of this project is to build an **end-to-end data analytics platform** integrating:  
1. **ETL & Data Cleaning** using **Talend Open Studio**  
2. **Data Warehouse** design and implementation in **PostgreSQL**  
3. **Interactive dashboards** in **Power BI**  
4. **Web-based analytics platform** with **Streamlit + Flask + PostgreSQL**  
5. **AI-powered chatbot** using **Dialogflow**
