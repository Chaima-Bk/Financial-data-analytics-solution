## 🌐 Web Application  

Developed using **Streamlit** and **Flask**, the web app allows analysts to interact dynamically with the chatbot and dasboards.  

### 🔐 Main Features  
- **Secure authentication** with bcrypt and PostgreSQL   
- **Dashboard visualization**  
- **Chatbot assistant** powered by Dialogflow  
- **Contact & support section**  

### 📁 Main Sections  
- Login / Sign Up  
- Dashboards Page   
- Chatbot Page  
- Contact Page  

---

## 🤖 Intelligent Chatbot  

Built with **Dialogflow**, the chatbot connects to the PostgreSQL database via a **Flask API**, allowing natural language queries such as:  

> 💬 “How many anomalies were detected this month?”  
> 💬 “Which agency recorded the highest transactions?”  
> 💬 “What’s the total number of international transactions?”  

It helps analysts **interact with data easily** and get instant insights.
